[★★★ 패키징 시 반드시 챙길 것 - 파일 인코딩/줄바꿈 (다음 채팅의 나에게)]
────────────────────────────────────────

배경:
  Claude는 리눅스 환경에서 파일을 생성/수정하므로 기본 출력이
  LF 줄바꿈 + UTF-8(BOM 없음)이 됨. Windows의 .bat / .iss / 한글 .txt는
  이 기본값으로는 깨짐. 곡천님이 매번 채팅 바뀔 때마다 .bat이 깨진다고
  보고했던 진짜 원인이 이것이었음. fix_a17부터 정규화 규칙을 명시함.

규칙 (zip 만들기 직전 필수 검사):
  1. 모든 .bat / .iss → CRLF 줄바꿈
  2. 한글 포함된 .bat / .iss → UTF-8 BOM (EF BB BF) 추가
  3. 한글 .txt (PATCH_NOTES, 사용안내, 빌드안내) → UTF-8 BOM + CRLF
  4. ASCII만 있는 .bat (build_exe.bat 등)도 CRLF는 필수
     (라벨/goto/if 멀티라인 블록이 LF에서 깨질 수 있음)

검증 명령:
  for f in *.bat installer/*.bat installer/*.iss; do
    file "$f"
  done
  → 출력에 "with CRLF line terminators" 가 있어야 함
  → 한글 포함 파일은 "UTF-8 (with BOM) text" 가 있어야 함

자동 정규화 스크립트 (Python, zip 만들기 전 한 번 실행):

  import glob, os
  TARGETS = ['*.bat', '*.iss', 'PATCH_NOTES_*.txt',
             '사용안내.txt', 'installer/*.bat', 'installer/*.iss',
             'installer/설치파일_빌드_안내.txt']
  files = []
  for pat in TARGETS:
      files.extend(glob.glob(pat))
  for path in files:
      if not os.path.exists(path):
          continue
      with open(path, 'rb') as f:
          data = f.read()
      if data.startswith(b'\xef\xbb\xbf'):
          data = data[3:]
      data = data.replace(b'\r\n', b'\n').replace(b'\n', b'\r\n')
      data = b'\xef\xbb\xbf' + data
      with open(path, 'wb') as f:
          f.write(data)
      print(f"{path}: 정규화 완료")

  # 주의: ASCII만 있는 .bat도 BOM이 들어가도 cmd.exe는 정상 동작.
  # 하지만 BOM이 unwanted 문자로 보이면 한글 없는 파일은 BOM 생략 가능.
  # 일관성을 위해 모두 BOM 추가하는 게 더 안전.

피해야 할 함정:
  - printf '\xEF\xBB\xBF' 같은 쉘 명령은 환경 따라 텍스트로 박힐 수 있음
    → 반드시 Python의 b'\xef\xbb\xbf' 사용
  - sed로 줄바꿈 변환 시 'sed -i s/$/\r/' 는 이미 CRLF인 파일에 \r를 또
    붙여 \r\r\n이 됨. Python으로 .replace(b'\r\n', b'\n') 후 다시
    b'\n' → b'\r\n'으로 정규화하는 게 안전.

이 규칙을 패치노트에 박제한 이유:
  매 채팅마다 곡천님이 "또 .bat 깨졌다"고 보고하는 사이클 차단.
  다음 채팅의 Claude가 zip 만들기 직전에 위 스크립트 한 번 실행.

  같이 우려 명시. 자신만만한 보고 후 실전에서 깨지면 곡천님 실망 큼.

- 패키징 규칙 (절대 준수):
  1. 파일 수정 시 fix 번호 +1 (덮어쓰기 금지)
  2. zip 파일명과 내부 폴더명 일치
  3. 이전 버전 파일 같이 묶지 않기
  4. 파일 하나만 전달 (한 번에 여러 버전 X)
  예외: 회귀 테스트 도구처럼 분리 자연스러운 경우는 분리 가능.

- 패키징 전 필수 검수:
  · main.py와 ui/index.html 양쪽 반영 확인 (grep/view)
  · JS 함수 존재 여부, HTML 이벤트 연결, 체크박스 disabled, init 초기화
  · .bat 파일들의 버전 표시 메시지도 새 버전으로 갱신

- 도구 대상: 곡천님 한 명이 아닌 모든 PUBG 스트리머용.
  → 다양한 PC 환경/캐릭터 의상/글자 조합에 robust 필요.
  → FHD/QHD 모두 지원 필수.

- 패치노트 작성 규칙 (a16부터 적용):
  · 단순 변경 사항만 적지 말 것.
  · 보류 항목 + 왜 보류했는지 + 해제 조건 같이 기록.
  · 향후 우선순위 명시.
  · 대화 맥락 / 합의된 방향 기록.
  → 이유: 다음 채팅의 Claude가 읽고 바로 작업 이어갈 수 있게.
