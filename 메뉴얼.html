1. 이 앱은 뭐예요?

PUBG 한 판이 끝나고 뜨는 결과창을 화면에서 읽어(OCR) 팀원 각자의 킬 수와 피해량(딜)을 숫자로 뽑고, 합계를 치지직 채팅에 자동으로 보내주는 도구예요. 딜 미션·킬 미션을 하는 방송에서 매판 숫자를 손으로 치는 일을 없애려고 만들었어요.

  • 읽는 것: 결과창의 킬 / 피해량 칸 (아래 그림의 네모 부분). 결과창 말고 다른 화면은 읽지 않아요.
  • 보내는 것: 설정한 형식의 채팅 한 줄 (예: !미션 3195). 치지직 공식 오픈 API로 곡천님 계정 대신 채팅을 써요.
  • 지원 화면: FHD(1920×1080), QHD(2560×1440) 전체화면·테두리 없는 창. 인원 모드는 솔로 / 듀오 / 4인 스쿼드 (3인 스쿼드는 준비 중).
이 앱은 화면의 픽셀을 읽는 방식이라, PUBG가 결과창 디자인을 바꾸면 인식이 깨질 수 있어요. 그럴 땐 업데이트가 나올 때까지 기다리거나 신고해 주세요.

2. 설치와 첫 실행

  1. pubg_streamer_helper_setup_fix_aNN.exe 를 실행해요. 설치할 때만 관리자 권한 창이 뜨고(Program Files에 설치해서), 앱 자체는 일반 권한으로 돌아요.
  2. Windows가 "알 수 없는 게시자"라고 막으면 추가 정보 → 실행을 눌러요. 개인 제작 앱이라 서명이 없어서 그래요.
  3. WebView2 런타임이 없는 PC면 설치 중에 자동으로 받아서 깔아요 (인터넷 필요). 이미 있으면 건너뛰어요.
  4. 설치가 끝나면 바탕화면 아이콘으로 실행해요. 첫 실행엔 아래처럼 30초 안내 카드가 떠요. "설명서 열기"를 누르면 이 문서가 열리고, 닫으면 다음부턴 안 떠요 (설정 탭 맨 아래 "사용 설명서 열기"로 언제든 다시 볼 수 있어요).

3. 치지직 연동 — 최초 1회만

채팅을 보내려면 치지직 개발자 센터에서 내 앱 키(Client ID / Secret)를 한 번 발급받아 넣어야 해요. 이 키는 내 PC의 데이터 폴더(%LOCALAPPDATA%\PUBG Streamer Helper\config.json)에만 저장되고 어디로도 전송되지 않아요. 설정 탭 → 파일 관리 → 데이터 폴더 버튼으로 열 수 있어요.

  1. 브라우저에서 치지직 개발자 센터(developers.chzzk.naver.com)에 방송 계정으로 로그인 → 애플리케이션 등록.
  2. 앱 이름은 아무거나(예: PUBG 헬퍼). 로그인 리다이렉트 URL에 아래를 정확히 적어요.
    http://127.0.0.1:8785/chzzk/callback
  3. 권한(API Scope)에서 채팅 메시지 쓰기를 켜요. 등록하면 Client ID와 Client Secret이 나와요.
  4. 앱의 설정 탭 → 치지직 연동에 두 값을 붙여넣고 인증 정보 저장.
  5. 치지직 연결을 누르면 브라우저가 열려요. 로그인 → 동의하면 앱으로 돌아오고, 제목줄 배지가 ● 연결됨으로 바뀌어요.
토큰은 만료 5분 전에 앱이 알아서 갱신해요. 방송 중에 갑자기 끊기면 연결 해제 → 치지직 연결을 한 번 다시 하면 돼요.

4. 기본 사용법 (F8 → F9)

  1. 한 판이 끝나고 결과창(팀원 캐릭터 4명이 서 있는 화면)이 보이는 상태에서 F8을 눌러요. 게임 창이 앞에 있어도 돼요 — 전역 핫키예요.
  2. 1초쯤 뒤 앱 메인 화면의 P1~P4 카드에 숫자가 채워지고, 아래 팀 합산이 떠요. 치킨이면 🍗 표시와 함께 보너스가 붙어요.
  3. 숫자가 맞으면 F9 — 채팅으로 전송돼요. (설정의 치지직 자동 전송이 켜져 있으면 F8만으로 바로 전송돼요. 숫자를 확인하고 보내고 싶으면 끄고 F9를 쓰세요.)
키하는 일
F8결과창 읽기 + 화면에 표시 (화면 직접 캡처 모드일 때). 메인의 이번 판 계산 버튼과 같아요.
F9마지막으로 읽은 결과를 채팅에 전송. 설정 탭의 결과 수동 전송 (F9) 버튼과 같아요. 스팀 모드에서도 동작해요.
F12스팀 스크린샷 (스팀 모드일 때 — 5절 참고).
결과창이 아닌 화면에서 F8을 누르면 "결과창이 아닌 화면으로 판단됨"이 뜨고 아무것도 보내지 않아요. 이건 정상이에요. 게임 중 화면에서 눌러 엉뚱한 숫자가 나가는 걸 막는 장치예요.

5. 캡처 방식 2가지

설정 탭 캡처 모드에서 골라요. 둘 중 하나만 쓰면 돼요.

① 화면 직접 캡처 (기본값)

F8을 누른 순간의 모니터 화면을 앱이 직접 찍어서 읽어요. 빠르고 설정이 없어요. 모니터가 여러 대면 모니터 번호를 PUBG가 떠 있는 쪽으로 맞춰 주세요 (새로고침을 누르면 목록이 갱신돼요).

② 스팀 스크린샷 자동 감지

스팀의 F12 스크린샷 기능을 그대로 써요. 결과창에서 F12를 누르면 스팀이 파일을 저장하고, 앱이 그 폴더를 감시하다가 새 파일이 생기면 자동으로 읽어요. PUBG가 F8을 먹어버리는 환경, 또는 이미 F12 습관이 있는 분께 맞아요.

  1. 캡처 모드를 스팀 스크린샷으로 바꿔요.
  2. 찾기로 스팀 스크린샷 폴더를 지정해요. 보통 이런 경로예요:
    C:\Program Files (x86)\Steam\userdata\[내 스팀ID 숫자]\760\remote\578080\screenshots
    (578080이 PUBG예요. 스팀 → 보기 → 스크린샷 → "디스크에서 보기"로 열면 정확한 폴더가 나와요)
  3. 스크린샷 딜레이는 스팀이 파일을 다 쓸 때까지 기다리는 시간이에요. 기본 0.8초면 대부분 충분하고, 읽은 결과가 자꾸 깨지면 1.5초로 늘려 보세요.
스팀 모드에서는 게임 중에 찍은 스크린샷도 앱이 한 번씩 들여다봐요. 결과창이 아니면 자동으로 걸러내지만, 밝은 하늘·모래밭 장면은 드물게 통과할 수 있어요. 방송 중엔 결과창에서만 F12를 누르는 습관이 가장 안전해요.

6. 인원 모드와 읽기 대상

인원 모드

모드언제비고
4인 (스쿼드)스쿼드 방송 (기본값)가장 많이 검증됐어요 (FHD 50판 + QHD 88판 전부 정확).
2인 (듀오)듀오 방송두 번째 캐릭터 다리가 숫자 칸을 가리는 자세에서 드물게 한 자리가 틀릴 수 있어요. 전송 전에 숫자를 한 번 확인해 주세요.
1인 (솔로)솔로 방송검증 표본이 적어요. 틀리면 신고해 주세요.
3인 (스쿼드)—아직 준비 중이라 선택이 막혀 있어요. 3인 판은 4인 모드로 읽으면 값이 틀려요.
자동 감지권장하지 않아요밝은 옷 캐릭터가 서 있으면 인원수를 잘못 볼 때가 있어요. 본인이 주로 하는 모드로 고정해 두는 게 가장 정확해요.

읽기 대상

딜량이면 카드와 합계가 피해량, 킬 수면 킬이에요. 채팅 형식의 {합계}가 이 선택을 따라가요.

7. 채팅 메시지·보너스·배수

메시지 형식

채팅으로 나갈 문장을 직접 써요. 중괄호 자리에 숫자가 들어가요.

자리표시자들어가는 값
{합계}읽기 대상에 따라 딜 합계 또는 킬 합계 (보너스·배수 적용 후)
{딜합계} / {딜}딜 합계 (보너스·배수 적용 후)
{킬합계} / {킬}킬 합계 (보너스 적용 후)

예: !미션 {합계} → !미션 3195 / !딜 {딜합계} !킬 {킬합계} → !딜 3195 !킬 27

치킨 보너스 · 킬 보너스

결과창이 #1 (치킨)이면 딜 합계에 보너스 딜량(기본 1000)을, 킬 합계에 보너스 킬 수(기본 10)를 더해요. 각각 체크로 켜고 끌 수 있어요. 메인 화면엔 +치킨 태그와 최종값이 같이 떠요.

결과값 배수

이벤트 날 "딜 2배" 같은 걸 할 때 써요. 보너스를 더한 뒤에 배수를 곱해요: (합계 + 보너스) × 배수.

설정 탭의 모든 항목은 바꾸는 즉시 저장돼요. 맨 아래 설정 저장 버튼은 한 번 더 확실히 저장하고 싶을 때 누르는 용도예요.

8. 기록 탭

  • F8로 읽은 판이 최근 순으로 최대 20개 남아요. 앱을 껐다 켜도 유지돼요 (history.json).
  • 한 줄을 누르면 펼쳐져서 P1~P4 각자의 숫자와 재전송 버튼이 나와요. 채팅이 안 나갔거나 한 번 더 보내야 할 때 써요.
  • 사용자가 값을 고친 기록에는 수정됨 (이전값 → 새값) 태그가 붙어요. 고치는 방법은 12절.
  • 전송에 실패하면 점이 회색(미송출)으로 남고 상태줄에 실패 이유가 떠요. 그 줄의 재전송으로 다시 보낼 수 있어요.

9. 자동 업데이트

  1. 앱을 켤 때마다 한 번 GitHub에서 최신 버전을 확인해요 (인터넷이 없으면 조용히 건너뛰어요).
  2. 새 버전이 있으면 배너가 뜨고, 업데이트를 누르면 설치 파일을 받아 설치 마법사를 실행한 뒤 앱이 종료돼요. 마법사에서 다음 → 다음만 누르면 끝이에요. 설정·기록·치지직 연결은 그대로 유지돼요.
  3. 지금은 바쁘면 ✕로 숨겨요. 다음에 켤 때 다시 알려줘요.
  4. 내려받은 설치 파일은 실행 전에 검증(SHA256)해요. 검증이 안 맞으면 실행하지 않고 안내만 떠요 — 그땐 릴리스 페이지에서 직접 받아주세요.
  5. 설정 탭 맨 아래 업데이트 확인으로 언제든 직접 확인할 수 있어요. 현재 버전도 거기 적혀 있어요.

10. 문제가 생겼을 때 (FAQ)

Q. F8을 눌러도 아무 반응이 없어요

  • 다른 프로그램(게임 자체 키 설정, OBS, 디스코드 등)이 F8을 먼저 잡고 있을 수 있어요. 앱 상태줄에 "핫키 등록 실패"가 떴다면 확실해요.
  • 해결: 그 프로그램에서 F8 설정을 풀거나, 캡처 모드를 스팀 스크린샷으로 바꿔 F12를 쓰세요.

Q. "결과창이 아닌 화면으로 판단됨"이 자꾸 떠요

  • 진짜 결과창인데 뜬다면: 모니터 번호가 맞는지, 게임이 전체화면/테두리 없는 창인지, 해상도가 FHD 또는 QHD인지 확인해요. 창모드로 작게 띄우면 읽지 못해요.
  • 결과창의 "다음" 페이지(상세 통계)에서는 읽지 않아요. 캐릭터 4명이 서 있는 첫 화면에서 눌러요.

Q. 숫자가 틀리게 나와요

  • 인원 모드가 실제 판과 맞는지 먼저 확인해요 (듀오 판을 4인 모드로 읽으면 엉뚱한 큰 숫자가 나와요).
  • 숫자 칸 위에 캐릭터 장식·팝업("매치가 진행 중" 등)이 겹쳐 있으면 틀릴 수 있어요. 팝업을 닫고 다시 F8.
  • 한 칸이 비정상적으로 큰 값(스쿼드 4,000 이상 등)으로 읽히면 앱이 그 칸을 0으로 두고 상태줄에 "상한 초과 → 0 처리"라고 알려요. 진짜 그 딜이었다면 수정으로 값을 넣어주면 돼요 (12절).
  • 그래도 틀리면 그 판의 스크린샷과 로그를 신고해 주세요. 실제 화면이 모여야 고칠 수 있어요.

Q. 치지직에 채팅이 안 올라가요

  • 제목줄 배지가 미연결이면 3절대로 다시 연결해요. 연결됨인데 안 나가면 치지직 자동 전송 체크가 꺼져 있고 F9를 안 누른 경우가 가장 많아요.
  • 개발자 센터에서 앱 권한에 "채팅 메시지 쓰기"가 켜져 있는지 확인해요.

Q. 앱 창이 "응답 없음"으로 잠깐 멈춰요

  • 켜자마자 빠르게 누르면 초기화 중이라 몇 초 그럴 수 있어요. 5초쯤 기다리면 풀려요. 창을 끌다가 멈추는 현상은 알려진 문제로 고치는 중이에요 — 그땐 트레이 아이콘에서 창을 다시 열어 보세요.

Q. Windows Defender가 설치 파일을 막아요

  • "추가 정보 → 실행"을 누르거나, 파일 우클릭 → 속성 → 맨 아래 차단 해제 체크 후 실행해요. 개인 제작 앱이라 코드 서명이 없어서 뜨는 경고예요.

Q. 창을 닫았는데 앱이 계속 떠 있어요

  • 창 닫기 시 트레이로 최소화가 켜져 있으면 ✕를 눌러도 트레이(작업표시줄 오른쪽 아래)로 숨어요. 완전히 끄려면 트레이 아이콘 우클릭 → 종료.

11. 개발자에게 신고하기

뭔가 안 되면 아래 두 가지를 곡천에게 보내 주세요. 이게 있어야 어디서 깨졌는지 알 수 있어요.

  1. 로그 파일: 설정 탭 → 파일 관리 → logs 버튼 → 열린 폴더의 events.log, errors.log. 토큰이나 비밀번호는 이 파일에 들어가지 않아요. (폴더 위치: %LOCALAPPDATA%\PUBG Streamer Helper\logs)
  2. 그 판의 스크린샷: 숫자가 틀린 경우엔 결과창 캡처가 꼭 필요해요. 캡처 이미지 저장이 켜져 있으면 screenshot 폴더에 F8 때 찍은 화면이 남아 있어요. 스팀 모드면 스팀 스크린샷 폴더의 파일이에요.
한 장보다 여러 판이 모이면 훨씬 빨리 고쳐져요. 틀린 판만이 아니라 맞은 판도 같이 있으면 비교가 돼서 더 좋아요.

12. 읽은 값 고치기 · 치킨 표시

OCR이 한 칸을 잘못 읽었거나, 치킨인데 보너스가 안 붙었을 때 쓰는 기능이에요. 합산 카드 오른쪽에 버튼 두 개가 있어요.

🍗 치킨 버튼

결과창의 순위 글자(#1)를 읽어 치킨을 판정하는데, 결과창이 막 뜨는 중이거나 채팅 오버레이가 순위를 가리면 못 읽을 때가 있어요. 그러면 상태줄에 "순위를 읽지 못했어요 — 치킨이면 🍗 버튼을 눌러주세요"가 뜨고 버튼이 노랗게 깜빡여요. 치킨이었으면 눌러서 켜고, 아니면 그냥 두면 돼요. 잘못 켜진 경우엔 다시 눌러 끄면 보너스가 빠져요.

수정 버튼

  1. 수정을 누르면 P1~P4의 킬·피해량 칸이 떠요. 지금 읽는 대상(딜 또는 킬)이 아닌 쪽은 흐리게 보이지만 같이 고칠 수 있어요.
  2. 틀린 칸만 고쳐요. 비워두거나 그대로 둔 칸은 바뀌지 않아요.
  3. 적용 — 앱 화면과 기록만 고쳐요. 채팅엔 안 나가요. 확인한 뒤 F9로 보내면 돼요.
    적용 후 전송 — 고친 값으로 채팅을 바로 보내요.
이미 채팅에 나간 결과를 고쳐서 다시 보내면, 채팅에는 틀린 값과 고친 값이 둘 다 남아요. 치지직 미션처럼 보낸 숫자를 목표에서 차감하는 봇을 쓰고 있다면 먼저 나간 틀린 값은 봇 쪽에서 따로 되돌려야 해요. 그래서 자동 전송을 켜둔 상태보다, 숫자를 보고 F9로 보내는 습관이 안전해요. (틀린 값을 앱이 자동으로 되돌리는 "수정 양식" 기능은 준비 중이에요.)
