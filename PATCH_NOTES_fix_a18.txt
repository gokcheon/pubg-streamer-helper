PUBG 스트리머 헬퍼 fix_a18 패치노트
=====================================

[메인 목표]
3인 스쿼드(squad3) 모드를 명시적으로 "미구현" 상태로 표시.
임시반영(0/6 정확도) 상태로 두면 사용자가 잘못된 OCR 결과를 보거나,
auto 모드 자동 감지가 squad3로 잘못 판정될 때 squad4 OCR이 어긋난
좌표로 동작해 가비지 결과가 송출될 위험이 있음.

→ 드롭다운에서 회색 비활성화 + 호버 툴팁 "미구현 (개발중)"
→ auto 감지든 수동 설정이든 squad3 진입 시 OCR 차단 게이트
→ squad3 OCR 코드/ROI는 그대로 보존 (본격 작업 시 게이트만 풀면 됨)

[버전 정리 안내]
fix_a18 = fix_a17 베이스 + squad3 미구현 게이트.
OCR 로직 변경 없음 → 회귀 테스트 baseline (스쿼드 52장 PASS) 그대로 유효.

곡천님 패키징 규칙(zip 파일명과 내부 폴더명 일치):
  zip = pubg_streamer_helper_1_0_fix_a18.zip
  폴더 = pubg_streamer_helper_1.0_fix_a18/

[★★★ 패키징 시 반드시 챙길 것 - 파일 인코딩/줄바꿈]
────────────────────────────────────────

(a17에서 박제됨 - 다음 채팅의 나에게)

배경:
  Claude는 리눅스 환경에서 파일을 생성/수정하므로 기본 출력이
  LF 줄바꿈 + UTF-8(BOM 없음)이 됨. Windows의 .bat / .iss / 한글 .txt는
  이 기본값으로는 깨짐.

규칙 (zip 만들기 직전 필수):
  1. 모든 .bat / .iss → CRLF 줄바꿈
  2. 한글 포함 파일 → UTF-8 BOM (EF BB BF) 추가
  3. 한글 .txt (PATCH_NOTES, 사용안내, 빌드안내) → UTF-8 BOM + CRLF
  4. ASCII만 있는 .bat도 CRLF는 필수

자동 정규화 스크립트 (Python):

  import glob, os
  TARGETS = ['*.bat', '*.iss', 'PATCH_NOTES_*.txt',
             '사용안내.txt', 'installer/*.bat', 'installer/*.iss',
             'installer/설치파일_빌드_안내.txt']
  files = []
  for pat in TARGETS:
      files.extend(glob.glob(pat))
  for path in files:
      if not os.path.exists(path):
          continue
      with open(path, 'rb') as f:
          data = f.read()
      if data.startswith(b'\xef\xbb\xbf'):
          data = data[3:]
      data = data.replace(b'\r\n', b'\n').replace(b'\n', b'\r\n')
      data = b'\xef\xbb\xbf' + data
      with open(path, 'wb') as f:
          f.write(data)

검증 명령:
  for f in *.bat installer/*.bat installer/*.iss; do file "$f"; done
  → "with CRLF line terminators" + "UTF-8 (with BOM) text" 확인
