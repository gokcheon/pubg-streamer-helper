PUBG 스트리머 헬퍼 fix_a19 패치노트
=====================================

[메인 목표]
앱으로서 갖춰야 할 편의 기능 추가:
  1. OCR 결과 미리보기 + F9 분리 송출 (잘못된 결과 송출 방지)
  2. 메인 카드 더블클릭 편집 + 가장 최근 기록 동기화
  3. 기록 탭 (메모리 20개, 펼침/재전송)
  4. 자동 토큰 복구 (사용자가 토큰 신경 안 쓰게)

회귀 테스트 baseline (스쿼드 52장 PASS) 그대로 유효. OCR 로직 변경 없음.

[변경 사항]
────────────────────────────────────────

A. 자동 토큰 복구 (사용자가 토큰 신경 안 쓰도록)
   1. send_message에 401 자동 갱신 + retry (만료 직전 통과 케이스 보호)
   2. 네트워크 에러/5xx → backoff retry (0.5s/1s/2s, 최대 3회 시도)
   3. 백그라운드 사전 갱신 워커 (만료 5분 전 미리 갱신)
      - 60초마다 점검, 5분 미만이면 갱신
      - 연속 실패 시 지수 backoff (60s → 120s → 240s, 최대 10분)
      - 5회 연속 실패 시 자동 갱신 중단 (refreshToken 만료 추정, 사용자 재연결 대기)
   4. refresh 실패 시 사용자 친화적 메시지: "치지직 연결을 다시 진행해주세요"
   5. cleanup에 stop_background_refresh 추가

B. F8 / F9 핫키 분리
   1. HotkeyManager에 send_callback 파라미터 추가
   2. F9 (VK_F9 = 0x78) 등록 → HOTKEY_ID_F9 (=2)
   3. F8 등록은 필수 (실패 시 전체 실패), F9는 선택 (실패해도 F8 살림)
   4. WebApi._on_hotkey_send → manual_send 호출
   5. F9 송출 = "결과 수동 전송" 버튼과 동일 동작

C. 결과 수동 전송 버튼 + 빈 카드 가드
   1. UI 버튼: btn → btn.accent (메인 계산 버튼과 동일 밝은 색)
   2. 라벨: "결과 수동 전송" → "결과 수동 전송 (F9)"
   3. manual_send 반환을 None → dict로 변경 (status 메시지 노출용)
   4. 카드 비었을 때: "전송할 결과가 없습니다" 상태 메시지
   5. F9 핫키 송출 시 poll_state로 send_status 노출 → UI에 3초간 표시

D. 메인 카드 더블클릭 편집
   1. 카드 c1~c4에 dblclick 리스너 (init에서 등록)
   2. 더블클릭 → input 박스 교체 → 엔터 확정 / Esc 취소 / blur로도 확정
   3. 카드 비었거나 숫자 아닌 경우 편집 불허
   4. 확정 시 update_last_result 호출 → 합계 재계산 + 가장 최근 기록 동기화
   5. read_target (damage/kill/both)에 따라 라벨에서 kill 값 추출
   6. 자동 전송 대기 중이면 메시지도 갱신된 값으로 교체

E. HistoryManager 클래스 신설
   1. 메모리 20개 보관, 앱 재시작 시 사라짐 (인게임 기록과 동일 정책)
   2. add(): F8 OCR 시점 자동 추가
   3. mark_sent_latest(): F9/auto_send 시점 송출됨 표시
   4. update_latest(): 카드 수정 시 가장 최근 항목 값 갱신 (수정 마크 안 함)
   5. get_by_id(): 재전송용 항목 조회

F. 기록 탭 UI
   1. 탭 순서: 메인 / 기록 / 설정
   2. 접힌 항목: 송출 점·텍스트 + 시간 + 모드 + 합딜 + 화살표
   3. 좌클릭 펼침 (한 번에 하나만, 자동 스크롤)
   4. 펼친 항목: 플레이어별 kill/dmg + 메타·재전송 한 줄 배치

   6. 송출 점 색: 초록(송출됨) / 흐린 회색(미송출)

[★★★ 패키징 시 반드시 챙길 것 - 파일 인코딩/줄바꿈]
────────────────────────────────────────

(a17에서 박제됨)

규칙: 모든 .bat / .iss / 한글 .txt → UTF-8 BOM + CRLF

자동 정규화 스크립트 (Python, zip 직전 실행):
  import glob, os
  TARGETS = ['*.bat', '*.iss', 'PATCH_NOTES_*.txt',
             '사용안내.txt', 'installer/*.bat', 'installer/*.iss',
             'installer/설치파일_빌드_안내.txt']
  files = []
  for pat in TARGETS:
      files.extend(glob.glob(pat))
  for path in files:
      if not os.path.exists(path):
          continue
      with open(path, 'rb') as f:
          data = f.read()
      if data.startswith(b'\xef\xbb\xbf'):
          data = data[3:]
      data = data.replace(b'\r\n', b'\n').replace(b'\n', b'\r\n')
      data = b'\xef\xbb\xbf' + data
      with open(path, 'wb') as f:
          f.write(data)
