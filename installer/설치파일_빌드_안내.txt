PUBG Streamer Helper - 설치 마법사 빌드 가이드
================================================

이 폴더(installer/)는 친구한테 줄 "설치 파일 (setup.exe)" 을 만드는
도구 모음입니다. fix_a17 부터 메인 앱 폴더 안에 함께 포함되어
배포되므로, 버전이 올라가도 별도 다운로드 / 경로 수정이 필요 없습니다.

한 번만 환경 세팅하면, 다음부터는 build_installer.bat 더블클릭으로
완성된 setup.exe 가 자동으로 나옵니다.

──────────────────────────────────────────────────────────────────
[1] 한 번만 하면 되는 환경 세팅
──────────────────────────────────────────────────────────────────

1) Inno Setup 6 설치
   - 아래 공식 링크에서 다운로드 (무료):
     https://jrsoftware.org/isdl.php
   - 페이지의 "innosetup-X.X.X.exe" (Stable Release) 받아서 설치
   - 기본 경로 그대로 ("Next > Next > Install")

2) Python 환경 확인
   - 평소 build_exe.bat 잘 돌아가는 PC 라면 그대로 OK
   - 즉 py launcher + pyinstaller + requirements.txt 설치된 상태면 됨
   - fix_a17 부터는 pystray 도 추가 (requirements.txt에 들어 있음)

──────────────────────────────────────────────────────────────────
[2] 폴더 구조 (fix_a17 부터 변경됨)
──────────────────────────────────────────────────────────────────

이전 버전(a16 까지)에서는 installer kit 이 별도 zip 으로 배포되어
앱 폴더 옆에 두는 구조였지만, fix_a17 부터는 메인 앱 폴더 안에
installer/ 서브폴더로 동봉됩니다.

  pubg_streamer_helper_1.0_fix_a25\        ← 메인 앱 (zip 푼 폴더)
      ├ main.py
      ├ build_exe.bat
      ├ app.ico
      ├ dist\                              ← PyInstaller 결과 (빌드 후)
      ├ dist_installer\                    ← setup.exe 출력 (빌드 후)
      ├ installer\                         ← 이 폴더
      │   ├ installer.iss
      │   ├ build_installer.bat
      │   └ 설치파일_빌드_안내.txt         (이 파일)
      └ ...

──────────────────────────────────────────────────────────────────
[3] 빌드 실행
──────────────────────────────────────────────────────────────────

이 폴더(installer/) 안의 build_installer.bat 더블클릭. 끝.

내부에서 자동 실행되는 단계:
  1) 메인 앱 폴더의 build_exe.bat 호출 → PyInstaller dist 생성
  2) Inno Setup 컴파일러 (ISCC.exe) 자동 검색
  3) installer.iss 컴파일 → setup.exe 생성

빌드 시간: 약 1~3분 (PyInstaller 가 가장 오래 걸림)

──────────────────────────────────────────────────────────────────
[4] 결과물 — 친구한테 줄 파일
──────────────────────────────────────────────────────────────────

  메인 앱 폴더\dist_installer\pubg_streamer_helper_setup.exe

(installer/dist_installer 가 아니라 한 단계 위, 앱 폴더 루트에 생성됨)

이 파일 하나만 친구에게 보내면 됩니다. 보통 30~50MB 정도 (압축 lzma2/ultra).

친구는 받은 setup.exe 더블클릭하면 끝.
  - 마법사 진행 (다음 → 다음 → 설치)
  - 관리자 권한 요청 시 "예" 클릭 (Program Files 에 설치하려면 필요)
  - 설치 도중 "WebView2 런타임 설치 중..." 메시지가 잠깐 뜸 (필요 시)
  - 완료 후 바탕화면 + 시작메뉴에 아이콘 자동 생성
  - "지금 실행하기" 체크하면 바로 실행

──────────────────────────────────────────────────────────────────
[5] 설치 마법사가 자동 처리하는 일
──────────────────────────────────────────────────────────────────

  ✓ 관리자 권한 요청 (UAC)
  ✓ 기존 버전 자동 제거 후 새 버전 덮어쓰기 (같은 AppId 라면)
  ✓ Program Files\PUBG Streamer Helper\ 에 파일 설치
  ✓ 바탕화면 + 시작메뉴 아이콘 자동 생성
  ✓ WebView2 런타임 자동 감지 → 없으면 다운로드 + 설치
    (이미 설치되어 있으면 건너뜀)
  ✓ 시작메뉴에 "PUBG Streamer Helper 제거" 항목 자동 등록
  ✓ Windows "앱 및 기능" 목록에 등록
  ✓ 제거 시 사용자 데이터 (로그/스크린샷) 보존, 빈 폴더만 정리

──────────────────────────────────────────────────────────────────
[6] 친구 PC 요구 사항
──────────────────────────────────────────────────────────────────

필수:
  - Windows 10 이상 (64비트 권장)
  - 인터넷 연결 (WebView2 다운로드용, 첫 설치 시 한 번만)
  - 관리자 권한

권장:
  - Windows 11 (WebView2 가 OS 기본 포함)

──────────────────────────────────────────────────────────────────
[7] 문제 해결
──────────────────────────────────────────────────────────────────

Q. "Inno Setup 을 찾을 수 없습니다" 에러
A. Inno Setup 6 을 설치했는지 확인. 설치 후 PC 재시작 권장.

Q. "Main app folder not found" 에러
A. installer/ 서브폴더를 메인 앱 폴더에서 빼지 마세요.
   build_installer.bat 은 한 단계 위(..)를 메인 앱 폴더로 가정합니다.
   zip 을 풀 때 폴더 구조가 흐트러진 경우 다시 풀면 됩니다.

Q. 친구가 받은 setup.exe 실행 시 "WebView2 다운로드 실패"
A. 친구 PC 인터넷 연결 확인. 회사/학교 PC 등 방화벽이 막는 환경이면
   친구가 직접 아래 링크에서 WebView2 받아 설치 후 setup.exe 재실행:
   https://developer.microsoft.com/microsoft-edge/webview2/

Q. 친구가 "이 앱은 PC를 손상시킬 수 있습니다" 라는 경고를 봄
A. 코드 서명 인증서가 없어서 SmartScreen 이 경고함. "추가 정보" →
   "실행" 누르면 됨. 정식 배포하려면 코드 서명 인증서 구매 (연 10~30만원)
   필요하지만 개인용 배포에는 굳이 필요 없음.

Q. fix_a17 첫 빌드 시 pystray 관련 에러
A. requirements.txt 에 pystray 가 추가되었으므로 빌드 전에 한 번:
     py -m pip install -r requirements.txt
   를 실행해서 pystray 를 설치해야 합니다.

──────────────────────────────────────────────────────────────────
[8] 버전 올라갈 때
──────────────────────────────────────────────────────────────────

fix_a17 부터는 installer kit 이 앱 폴더 안에 동봉되므로,
새 버전 zip 을 받으면 그대로 풀고 build_installer.bat 더블클릭이면
끝입니다. installer.iss / build_installer.bat 의 경로를 수동 수정할
필요가 없습니다.

다만 새 패치마다 installer.iss 의 다음 한 줄은 새 버전 번호를 반영하도록
패키징 시점에 자동 갱신됩니다:

  #define MyAppVersion "1.0 fix_a25"      ← 새 패치마다 갱신됨

이건 제작자(곡천님 측)가 zip 만들 때 미리 처리하므로, 빌드하는 사람은
신경 쓸 필요 없음.
