﻿PUBG 스트리머 헬퍼 — 사용 안내
=================================

PUBG 게임 결과화면을 자동으로 인식해서 치지직 채팅에 전송하는 도구입니다.


[설치]

1. setup.exe 실행 → 안내대로 설치
   - 관리자 권한 필요 (자동 요청됨)
   - WebView2 미설치 시 자동 설치됨
   - C:\Program Files\PUBG Streamer Helper 에 설치됨

2. 첫 실행 시 환경 검사:
   - OneDrive 경로 감지 → 다른 경로로 이동 필요
   - WebView2 미설치 → 자동 안내
   - 한글/특수문자 경로 감지 → 경고 (대부분은 정상 동작)

3. 치지직 인증
   - 치지직 개발자 페이지에서 client_id, client_secret 발급
   - 앱 → 설정 → 입력 후 "인증 정보 저장"
   - "치지직 연결" 버튼 클릭 → 브라우저에서 로그인


[기본 사용법]

1. PUBG 결과 화면이 보이는 상태에서 F8
2. 자동으로 OCR 처리 후 치지직 채팅에 전송
3. 결과창 아닌 화면에서 F8 → 자동 차단됨

캡처 모드 두 가지:
- 화면 캡처: F8 시점에 모니터 캡처 (기본값, 빠름)
- 스팀 모드: 스팀 스크린샷 폴더 감시 → 자동 감지 (F12로 스팀 스크린샷 찍으면 자동 처리)

게임 모드 (4가지):
- solo / duo / squad3 / squad4
- auto: 자동 감지 (squad3/squad4 혼동 가능, 권장 안 함)
- 평소 본인 자주 하는 모드 고정 권장


[문제 해결]

▸ "결과창이 아닌 화면으로 판단됨" 메시지가 자주 뜸
  - 정상 동작입니다. 결과창에서만 OCR이 돌아가도록 의도됨.
  - 진짜 결과창인데 막히면 설정에서 "결과창 게이트" 해제 가능 (권장 안 함)

▸ F8이 안 먹힘
  - 다른 프로그램이 F8 핫키를 점유 중일 수 있음 (게임 자체 단축키, OBS 등)
  - 설정 → 핫키 비활성화 후 스팀 모드로 전환 권장

▸ "응답 없음" 표시
  - 앱 시작 직후 빠르게 클릭하면 잠깐 발생 가능 (정상)
  - 5초 정도 기다리면 풀림

▸ Windows Defender가 setup.exe 차단
  - "추가 정보" → "실행" 클릭
  - 또는 SmartScreen 우회: 우클릭 속성 → 일반 → "차단 해제" 체크

▸ 캡처 모드에서 OCR이 잘 안 됨
  - 다중 모니터 사용 시: 설정에서 PUBG가 띄워진 모니터 번호로 변경
  - DPI 스케일링이 125% 이상이면 일부 환경에서 영향 가능

▸ 토큰 만료 / 치지직 연결 끊김
  - 설정 → "연결 해제" → "치지직 연결" 다시


[개발자에게 문제 신고]

뭔가 안 되면 events.log를 보내주세요:

  설정 탭 → "logs" 버튼 클릭 → 폴더 열림
  → events.log 와 errors.log 두 파일 첨부

이 두 파일에 어떤 환경에서 어떻게 깨졌는지 다 들어있습니다.
민감한 정보 (토큰, 비밀번호) 는 따로 token.json에 저장되며 위 두 파일엔 없습니다.


[참고]

- 본 도구는 PUBG 결과창 픽셀을 OCR로 인식하는 방식입니다.
  PUBG가 결과창 UI를 변경하면 인식이 깨질 수 있고, 그때마다 패치가 필요합니다.
- 치지직 OAuth 토큰은 로컬에 저장됩니다 (외부로 전송 안 함).
- 캡처는 결과화면만 사용하며, 게임 플레이 중 화면은 캡처하지 않습니다.
