PUBG 스트리머 헬퍼 fix_a12 패치노트
=====================================

[메인 목표]
듀오 모드 OCR 정확도 100% 확보 (19/19, 흰신발 케이스 포함)

[배경]
fix_a11까지 솔로/스쿼드4 모드는 검증되었으나, 듀오 모드는 ROI 좌표가
부정확하고 글자 색상이 흰색이 아닌 베이지/연노란색이라 기존 마스크로는
인식 불가능한 상태였음.

추가로 곡천님이 우려한 "흰 신발/옷 등이 박스 우측에 침범하는 케이스"
도 OCR 정확도 떨어뜨리는 요인이라 해결 필요.

[10장 듀오 캡처 분석 결과]

1. 듀오 박스 위치 (FHD 1920x1080 기준):
   - P1 (본인) 박스: x=540-630, y=706-728 (킬), y=784-806 (데미지)
   - P2 (팀원) 박스: x=1070-1160, y=706-728, y=784-806
   - 박스 폭은 90px (캐릭터 다리/신발 침범 방지)

2. 듀오 글자 색상 (큰 발견):
   - P1 (본인) 글자: 베이지/연노란색 (BGR≈[140, 200, 213], R-B≈72)
   - P2 (팀원) 글자: 흰색 (BGR≈[220, 220, 220], R-B≈0)
   - 두 색을 모두 인식해야 함

3. 듀오 글자 크기:
   - 한자릿수 폭: 6-9px (1, 7은 좁음)
   - 다자릿수: 한자리당 약 9-11px
   - 높이: 19-20px
   - 솔로(28px), 스쿼드4(16px)와 다른 중간 크기

[변경 사항]

1. _to_binary_variants(image_bgr, mode) 에 mode 인자 추가
   - duo 모드: 베이지(R>200, G>170, B>130, R>B+20) + 흰색(R≈G≈B>200) OR 마스크
   - solo/squad4 모드: 기존 Otsu (변경 없음)
   - 흰 신발이 박스에 침범해도 색상 마스크가 자동 분리

2. _prepare_band의 mode 분기에 duo 추가
   - duo 모드도 solo와 동일하게 vert_mask 비활성화

3. get_template_path에 duo 분기 추가
   - duo 모드: digit_templates_strip_duo.png 사용

4. 듀오 전용 strip (digit_templates_strip_duo.png) 신규 생성
   - 10장 캡처에서 0~9 글자 각각 추출
   - INTER_AREA로 11x20 cell로 다운스케일
   - column 활성도 임계값 3 (잡음 제거)

5. 1/7 분류 패널티 임계값 조정
   - 1 패널티: mid_w >= 9 → mid_w >= 6
   - 7 패널티: mid_w <= 5 → mid_w <= 4
   - 듀오 글자가 작아 진짜 7의 mid_w가 6-7인데 기존 임계값 9에서는
     1로 잘못 인식되는 문제 해결 (예: 227 → 221, 137 → 131)
   - 솔로/스쿼드4의 진짜 1(mid_w=2-3), 진짜 7(mid_w=9-11)에는 영향 없음

6. _recognize_squad4_rule이 _to_binary_variants 호출 시 mode 전달

7. config.json:
   - duo ROI 좌표 갱신 (정확한 픽셀 측정 결과)
   - recognizer.template_strip_duo: "digit_templates_strip_duo.png" 추가
