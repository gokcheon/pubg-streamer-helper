PUBG 스트리머 헬퍼 fix_a11 패치노트
=====================================

[메인 목표]
환경 경고 "무시하고 계속" 버튼 무한 루프 버그 수정

[배경]
fix_a10 빌드된 exe 를 Program Files 에 설치하고 일반 권한으로 실행하면
"로그 폴더 쓰기 권한 없음" 환경 경고 창이 뜨는 게 정상.

문제는 사용자가 "무시하고 계속" 버튼을 눌러도 앱이 정상 실행되지 않고
같은 환경 경고 창이 다시 뜨는 무한 루프가 발생.

[원인]
main() 의 흐름:
  1. check_environment() → 환경 문제 감지
  2. 환경 경고 창 표시
  3. 사용자가 "무시하고 계속" 클릭 → win.destroy()
  4. subprocess.Popen([sys.executable]) 으로 새 프로세스 시작
  5. 현재 프로세스 return 으로 종료
  6. 새 프로세스가 다시 1번부터 시작
  7. 환경 문제는 그대로 → 또 환경 경고 → 사용자가 또 누름 → 또 재시작 → ...

새 프로세스가 다시 환경 검사를 똑같이 통과하지 못 해서 같은 경고가 무한 반복.

[변경 사항]

main.py main() 함수 환경 검사 흐름 수정:

1. 환경변수 PUBG_HELPER_SKIP_ENV_CHECK 도입
   - 값이 "1" 이면 환경 검사를 건너뛰고 바로 메인 앱 흐름으로 진행

2. "무시하고 계속" 클릭 시 새 프로세스 띄울 때 위 환경변수를 함께 전달
   - subprocess.Popen([...], env=new_env) 형태로 환경변수 사본 + 플래그 추가

3. 결과:
   - 사용자가 "무시하고 계속" 한 번 누르면 → 새 프로세스가 검사를 건너뛰고 정상 실행
   - 환경 문제 자체는 해결되지 않지만 (앱 종료 전까지 그대로),
     사용자 의도대로 "무시하고 계속 사용" 동작이 작동

[변경 안 한 항목]

- 같은 프로세스에서 webview 창을 닫고 다시 메인 창을 띄우는 방식은 채택 안 함
  → pywebview 가 한 프로세스에서 webview.start() 를 두 번 호출하는 걸
    잘 지원하지 않을 가능성이 있어, 재시작 흐름을 유지하는 쪽이 안전

- check_environment() 자체의 검사 항목은 그대로
  → 권한 문제를 사용자에게 알리는 건 정상 동작이고, 다만 무시 후 진행이
    가능하도록만 수정

[backward compatibility]
- 환경변수가 없으면 기존 동작 그대로 (검사 수행)
- "무시하고 계속" 버튼 동작이 의도대로 작동하도록 수정
- 외부 API 변경 없음, config.json 변경 없음

[검증]
- 솔로 OCR 회귀 검증: 8/8 (100%) - fix_a10 과 동일
- 환경 경고 흐름 자체는 곡천님 PC 에서 실제 빌드/설치/실행으로만 검증 가능

[빌드 스크립트]
- build_exe.bat 헤더 버전: fix_a10 → fix_a11
- package_dist.bat zip 파일명 패턴: fix_a10 → fix_a11
