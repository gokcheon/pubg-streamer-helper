[1] 한 줄 요약
올리기.bat 이 실행 즉시 닫히던 문제 수정. 그 외 변경 없음 (a26 = 첫 배포 준비, a27 = 그 핫픽스). 앱 코드·OCR 무변경, 회귀 baseline 그대로 유효.

[2] 문제 원인
올리기.bat 의 "회귀 캡처 자동 복사" if-else 블록 안에 있던 echo 문에 닫는 괄호 ")" 가 들어 있었다:
  echo  [주의] ... 회귀 캡처 없이 올라가요 (앱 동작엔 영향 없음).
cmd 는 괄호 블록 안의 ")" 를 블록의 끝으로 읽기 때문에 문법 오류 → 창이 즉시 닫힘. pause 줄까지 가지도 못했다.
깃허브에는 아무것도 올라가지 않았다 (오류 블록이 git init 보다 앞에 있음).

[3] 고친 것
- 해당 echo 의 괄호를 " - " 로 바꿈. 블록 안 echo 에 ")" 가 남아 있는지 스크립트로 전수 확인 (0건).
- 안전장치: 맨 위에서 자기 자신을 cmd /c 로 한 번 더 호출하고, 어떤 경로로 끝나든 바깥 창이 "아무 키나 누르세요" 로 붙잡는다.
  앞으로 문법 오류가 또 생겨도 오류 메시지를 읽을 수 있다.
- version.py APP_FIX=27, installer.iss 기본 AppVer 1.0.27, bat 표기 fix_a27, 메뉴얼 헤더 fix_a27.
