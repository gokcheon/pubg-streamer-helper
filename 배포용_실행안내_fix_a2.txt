PUBG Streamer Helper fix_a2 - 배포 및 실행 안내
================================================

[ 개발자용: 배포 패키지 만드는 방법 ]

1. build_exe.bat 실행
   - Python, 필요 패키지 자동 설치 후 exe 빌드
   - 완료되면 dist\pubg_streamer_helper 폴더 생성됨

2. package_dist.bat 실행
   - dist\pubg_streamer_helper 폴더를 zip으로 자동 압축
   - pubg_streamer_helper_fix_a2_날짜.zip 생성됨

3. 이 zip 파일을 상대방에게 전달


[ 사용자용: 처음 실행하는 방법 ]

1. 받은 zip 파일을 C:\pubg_helper 같은 일반 폴더에 압축 해제
   ※ 주의: 아래 경로에서 실행하면 오류 날 수 있습니다
     - OneDrive 바탕화면 (가장 흔한 원인)
     - 다운로드 폴더 (OneDrive 동기화 중이면 동일)
     - 압축 파일 내부에서 바로 실행

2. pubg_streamer_helper 폴더 안에
   pubg_streamer_helper.exe 와 _internal 폴더가 같이 있어야 합니다.
   exe 파일만 따로 꺼내서 실행하면 안 됩니다.

3. pubg_streamer_helper.exe 실행


[ 오류 발생 시 확인사항 ]

"Python.Runtime" 또는 "pythonnet" 관련 오류:
 → 압축 해제 경로가 OneDrive/클라우드 폴더인지 확인
 → C:\pubg_helper 로 옮겨서 다시 실행

"_internal 폴더 없음" 또는 dll 오류:
 → exe 파일만 따로 꺼낸 경우 → 폴더째 사용

그래도 안 되면:
 → logs\errors.log 파일을 개발자에게 전달
