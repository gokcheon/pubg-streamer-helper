PUBG 스트리머 헬퍼 1.0 fix_a29 — 패치 노트 (실험 일지 형식)
작성일: 2026-08-20
=====================================================================

[1] 한 줄 요약
점검 보고서의 나머지 항목. ① 사용자 데이터를 %LOCALAPPDATA%\PUBG Streamer Helper 로 이동 + 앱을 일반 권한으로 실행(바로가기 관리자 플래그 제거)
+ 언인스톨 시 개인 데이터 정리/삭제 질문 ② 모드별 현실 딜 상한 + 상한 초과 경고 ③ 설치 파일 SHA256 검증 ④ OAuth state 난수화
⑤ 모니터 새로고침 캐시 무시 ⑥ 기본 메시지 양식 통일 ⑦ 설정에 "데이터 폴더" 버튼. OCR 숫자 인식 무변경, 회귀 52/52.

[2] 핵심 결정과 이유

2-1. 데이터 폴더 분리 (get_data_dir / DATA_DIR)
   - 설치판(frozen) = %LOCALAPPDATA%\PUBG Streamer Helper. 폴더판(python main.py) = 예전처럼 앱 폴더 (곡천님 개발 흐름 유지). 환경변수 PUBG_HELPER_DATA_DIR 로 강제 가능.
   - 이유: Program Files 에 쓰려고 바로가기에 '관리자 권한으로 실행' 을 걸어 왔는데, 그 때문에 매 실행 UAC, 관리자 프로세스에서 브라우저 열기 불안정(설명서·OAuth 창),
     시작프로그램 등록 불가, 토큰·설정이 Program Files 에 잔존했다. 코드상 관리자 권한이 필요한 경로는 없다.
   - 마이그레이션(migrate_legacy_data_dir): 새 DATA_DIR 에 config.json 이 없고 exe 옆에 있으면 config.json / config.backup.json / chat_tokens.json(또는 config 의 token_file) / history.json 을 복사.
     원본은 남겨 롤백 가능. logs/migration.log 에 기록. 로그·스크린샷·디버그는 옮기지 않는다(새 폴더에서 새로 시작).
   - 설치마법사는 여전히 PrivilegesRequired=admin (기존 Program Files 설치를 덮어써야 하므로). 바로가기 AfterInstall: SetElevationBit 제거, [Run] 은 runasoriginaluser.
     기각: PrivilegesRequired=lowest 로 바꾸기 — 기존 HKLM 설치와 별개로 두 번째 설치가 생겨 AppId 가 충돌한다.
   - 언인스톨: [UninstallDelete] 가 a28 이하가 exe 옆에 남긴 토큰·설정·기록·logs 를 정리하고, CurUninstallStepChanged 에서 LOCALAPPDATA 데이터 폴더 삭제 여부를 묻는다(기본 "아니요" 권장 — 재설치 시 이어 씀).
   - 영향 받는 상수: CONFIG_PATH / CONFIG_BACKUP_PATH / HISTORY_PATH / TOKENS_PATH / LOGS_DIR / SCREENSHOTS_DIR / DEBUG_DIR / BUILD_LOGS_DIR / OVERLAY_PATH / OUTBOX_PATH / .running.lock / resolve_path(로그 경로).
     중복 정의돼 있던 상수 블록(2벌) 을 하나로 정리.
   - 주의: OBS 가 overlay.txt 를 텍스트 소스로 읽고 있었다면 경로가 바뀐다 → %LOCALAPPDATA%\PUBG Streamer Helper\overlay.txt 로 다시 지정. (메뉴얼 미기재 — 다음 갱신 때 추가)

2-2. 모드별 딜 상한 (config.sanity.max_damage_per_player_by_mode)
   - 기본 solo 6000 / duo 5000 / squad3 4500 / squad4 4000, 전역 상한 10000 과 min. 초과 칸은 0 처리 + result["warnings"] → 상태줄 "P3 딜 9999은 상한(4000) 초과 → 0 처리 — [수정]으로 바로잡아 주세요".
   - 곡천님: "스쿼드에서 혼자 3000딜 이상은 드묾, 간혹 있음" → 3000 이 아니라 4000 으로 여유. 진짜 그 딜이면 [수정] 으로 복구 가능하므로 오차단 비용이 낮다.

2-3. 설치 파일 SHA256
   - build.yml 이 exe 옆에 .sha256 을 만들어 릴리스에 같이 올린다. updater 는 .sha256 자산이 있으면 내려받은 파일 해시를 비교, 불일치면 삭제 후 실행 거부.
   - a29 이전 릴리스엔 .sha256 이 없으므로 검증 없이 진행(하위 호환). a29 부터 올라가는 릴리스는 검증된다.

2-4. 기타
   - OAuth state: secrets.token_urlsafe(16).
   - refresh_monitors(): 캐시 시각 초기화 후 재측정 (예전엔 60초 캐시 때문에 [새로고침] 이 즉시 반영 안 됨).
   - get_config 기본 메시지 양식 "!미션 {합계}" 로 계산부와 통일.
   - check_environment 의 로그 쓰기 경고 문구를 데이터 폴더 기준으로.
   - 설정 탭 파일 관리에 [데이터 폴더] 버튼 (open_folder "data").

[5] 잠재 함정
- DATA_DIR 은 import 시점에 고정. 테스트에서 바꾸려면 PUBG_HELPER_DATA_DIR 환경변수를 프로세스 시작 전에.
- 마이그레이션은 DATA_DIR 에 config.json 이 "없을 때만" 1회. 새 폴더에서 한 번이라도 실행된 뒤엔 exe 옆 파일을 다시 보지 않는다.
- 언인스톨 삭제 질문은 관리자 컨텍스트의 {localappdata} — UAC 동일 사용자 승격이면 같은 폴더. 다른 관리자 계정으로 승격하면 그 계정의 폴더를 본다(흔치 않음).
- 남은 미해결: 수정 양식(2회 전송) 음수 테스트 대기, OCR 게이트·인원 감지 교체, UI 통일, 드래그 freeze, 듀오 2000+ 원본 캡처.
